# Міні-СУБД на Python (Лабораторна робота №4)

Цей проєкт реалізує спрощену систему управління даними (міні-СУБД) на Python, використовуючи об'єктно-орієнтований підхід та патерни проєктування, згідно з вимогами завдання.

## Архітектура та Патерни

Система побудована на наступних ключових компонентах:

### 1. Патерн Singleton (Database)

* **`database.py`**: Клас `Database` реалізовано як **Singleton**. Це гарантує, що в рамках одного застосунку існує лише один екземпляр бази даних, який централізовано керує всіма таблицями.

### 2. Патерн Factory Method (Створення таблиць)

* **`database.py`**: Метод `Database.create_table()` діє як **Factory Method**. Він приймає декларативну схему (словник) і створює готові об'єкти `Table` та `Column`, автоматично мапінгуючи строкові типи даних (`'int'`, `'string'`) до відповідних класів валідації (`IntegerType`, `StringType`).

### 3. Основні Структури Даних

| Клас | Файл | Роль |
| :--- | :--- | :--- |
| **`DataType`** | `data_types.py` | Абстрактний базовий клас для всіх типів. Забезпечує архітектуру для легкого додавання нових типів даних. |
| **`Column`** | `table.py` | Описує структуру колонки: назва, тип, обмеження (`nullable`, `primary_key`). |
| **`Table`** | `table.py` | Колекція об'єктів `Column` та `Row`. Відповідає за **CRUD** (Insert, Select) та **Агрегатні функції** (`COUNT`, `SUM`, `AVG`). |
| **`Row`** | `table.py` | Зберігає дані одного запису та його унікальний `id`. |

### 4. Підтримка Обмежень

* **Валідація типів:** Кожен тип даних має метод `validate()`.
* **NOT NULL:** Перевіряється у `Column.validate()`.
* **Primary Key:** Перевіряється на унікальність під час операції `Table.insert()`.
